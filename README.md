### 1. IntraSight-ESI · Retrospective research

Can patients within the same triage stratum have different risks? A public NHAMCS analysis with a later-year holdout: **5.31× outcome enrichment** in the primary stratum. IMMEDR is a proxy, not confirmed ESI; clinical validation remains pending.
